# PokeNZA data

Static data updates for the PokeNZA app, served by GitHub Pages.

- Base URL: https://tng1027.github.io/pokenza-data/
- Files are generated by `tools/bundle-builder` in `tng1027/pokenza-app`.
- Do not edit files by hand. Published files are immutable.

Layout:

```text
latest.json
bundles/<version>/manifest.json
bundles/<version>/pokemon_data.sqlite
objects/<sha256>.webp
```
